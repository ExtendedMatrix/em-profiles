# Community packages

One folder per package, `profiles/<id>/`, named as the package id, with its
curators in `.github/CODEOWNERS`. See [CONTRIBUTING.md](../CONTRIBUTING.md)
and [SPEC.md](../SPEC.md).

- [`geofisica/`](geofisica/) — geophysical slices, sections and volumes
  (GPR, ERT, magnetometry) as documents, and the anomalies read on them as
  USD units with their extractor. A mixed package (data + code), 0.1.0,
  `proposed`; built row by row (the geophysics plan, 19 November 2026).

The statuary pilot, with its curators and its data, will follow; the
invented archives in [`examples/`](../examples/) show the form.
