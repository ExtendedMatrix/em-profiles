# Community packages

One folder per package, `profiles/<id>/`, named as the package id, with its
curators in `.github/CODEOWNERS`. See [CONTRIBUTING.md](../CONTRIBUTING.md)
and [SPEC.md](../SPEC.md).

None yet. The first will be the statuary pilot, with its curators and its
data; until then the invented archives in [`examples/`](../examples/) show
the form.
